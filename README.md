# HU Editor

Abaqus / Nastran 해석 입력 파일용 대용량 텍스트 에디터. Rust 코어 + Tauri 2 (Svelte) UI.

## 구조

```
crates/hu-core/   디스크 기반 문서: 블록 캐시, 백그라운드 줄 인덱스, 뷰포트, 검색, Markdown 변환 (UI 의존성 없음)
crates/hu-gen/    합성 테스트 덱 생성기 (Abaqus .inp / Nastran .bdf)
app/              Tauri 2 앱 (src-tauri: IPC 커맨드, src: Svelte 프론트엔드, e2e: 화면 시나리오)
```

## 실행

```sh
cd app
npm install
npm run tauri dev
```

## 테스트 / 벤치마크

```sh
cargo test --workspace
cargo run --release -p hu-gen -- nastran 30G /path/to/plates.bdf      # abaqus | nastran, 크기 500M / 2G / 30G ...
cargo run --release -p hu-core --example bench -- /path/to/plates.bdf [검색어]
```

### 화면 시나리오

실제 화면 코드를 브라우저에서 실제 코어와 연결해 돌리고, 사용자가 보는 결과를 확인합니다. 설치된 Chrome(Windows에서는 Edge)을 씁니다.

```sh
cd app
npm run e2e                # 전체
npm run e2e -- box tabs    # 이름을 지정한 시나리오만 (e2e/scenarios/)
npm run e2e -- --verbose   # 통과한 항목도 표시
npm run e2e -- --keep      # 테스트 파일과 스크린샷을 지우지 않고 위치를 알려 줌
npm run e2e -- --big       # 1GB 덱 시나리오도 함께 (느리고 디스크가 필요함)
```

Tauri 명령 층은 `e2e/bridge`가 대신합니다. 앱에 명령을 추가하면 브리지에도 추가해야 하고, 빠져 있으면 시나리오를 시작하기 전에 알려 줍니다. 실제 창과 네이티브 대화 상자는 이 시나리오로 확인되지 않습니다.

## 파일 메뉴

VS Code의 파일 메뉴에서 작업 영역·프로필·공유처럼 이 편집기에 없는 개념은 빼고 나머지를 따랐습니다.

- **새 파일…**: 텍스트 파일, Abaqus 입력 파일, Nastran 입력 파일 중에서 고르면 그 문법의 새 문서가 열립니다(처음 저장할 때 Nastran은 `.bdf`, 나머지는 `.inp`를 제안). 파일 이름을 입력하면 저장 대화 상자에서 위치를 정해 빈 파일을 바로 만들고 엽니다. 이미 있는 파일은 덮어쓰지 않습니다.
- **새 창**: 아무것도 열려 있지 않은 창을 엽니다. 지난 세션을 다시 열지 않고, 이 창의 배치는 저장하지 않습니다.
- **폴더 열기…**: 작업 영역이 없으므로 고른 폴더를 탐색기에서 펼쳐 보여 줍니다.
- **최근 항목 열기**: 최근에 연 파일 10개(창끼리 공유, 50개까지 기억), 닫힌 편집기 다시 열기, 기타…(Ctrl+R, 전체 목록에서 검색), 최근에 연 항목 지우기. 디스크에서 사라진 파일을 고르면 알리고 목록에서 뺍니다.
- **자동 저장**: 켜면 파일을 마지막 편집 1초 뒤에 저장합니다(설정 창에도 있음). 새 파일은 이름이 없어 저장하지 않고, 그사이 다른 프로그램이 파일을 바꿨으면 덮어쓰지 않고 "디스크에서 파일이 변경되었습니다." 알림을 띄웁니다. 저장은 파일 전체를 다시 쓰므로 수 GB 파일에서는 켜지 않는 편이 좋습니다.
- **파일 되돌리기**: 저장하지 않은 변경을 버리고 디스크의 내용으로 돌아갑니다. 보던 줄은 그대로입니다.
- **끝내기**: 모든 창을 닫습니다. 창마다 저장하지 않은 변경이 있으면 따로 묻습니다. **창 닫기**는 이 창만 닫습니다.

## 파일에서 찾기

찾기 메뉴의 파일에서 찾기·파일에서 바꾸기는 UltraEdit처럼 다른 찾기 기능과 함께 찾기 메뉴에 있습니다. 왼쪽 끝의 활동 표시줄에서 탐색기와 검색 보기를 바꿉니다(보이는 보기를 다시 누르면 사이드바를 숨김). 작업 영역이 없으므로 검색 보기에는 **검색할 폴더** 칸이 따로 있고, 처음에는 열려 있는 파일의 폴더가 들어갑니다.

- 입력하는 대로 찾고, 폴더 안의 파일을 탐색기와 같은 순서(폴더 먼저, 이름순)로 보여 줍니다. 숨김 파일·폴더, 링크된 폴더, 이진 파일(앞부분에 NUL 바이트)은 건너뜁니다. 대소문자 구분, 단어 단위로, 정규식은 찾기 창과 같습니다.
- `…` 버튼으로 **포함할 파일**과 **제외할 파일**을 엽니다. VS Code처럼 쉼표로 나눈 glob이고(`*.inp, sub/*.bdf`, `**/inc.*`, `*.{inp,bdf}`), `/`가 없으면 어느 깊이의 이름에도 맞으며, 폴더에 맞으면 그 안이 모두 포함·제외됩니다. 대소문자는 가리지 않습니다.
- 열려 있는 파일은 저장하지 않은 변경까지 포함해 편집기의 내용으로 찾습니다. 결과를 누르면 그 파일이 열리고 찾은 부분이 선택됩니다. 결과는 VS Code처럼 처음 20,000개까지입니다.
- **모두 바꾸기**는 몇 개 파일의 몇 개 항목을 바꿀지 묻고 나서 바꿉니다. 열려 있지 않은 파일은 바꾸고 바로 저장하고, 열려 있는 파일은 편집기에서 바꾼 채로 두어 실행 취소할 수 있습니다(저장은 직접).

## 찾기 창

VS Code처럼 편집 영역 오른쪽 위에 떠 있습니다. 찾은 항목이 창 밑에 가리면 그 줄을 아래로 스크롤해 보여 주고, 파일 맨 위라서 더 내릴 수 없으면 본문을 창 높이만큼 아래로 밀어 둡니다(스크롤하거나 창을 닫으면 원래대로).

- **개수**: 찾을 말 옆에 `3/120`처럼 지금 선택한 항목이 몇 번째인지와 전체 개수가 나옵니다. 선택이 항목이 아니면 `?/120`입니다. 개수는 찾을 말이나 본문이 바뀔 때만 다시 세고, 큰 파일은 세는 동안 진행률을 보여 줍니다.
- **정규식** (`.*`): 한 줄 안에서 찾습니다. `^`와 `$`는 줄의 처음과 끝이고, 줄바꿈은 찾을 수 없습니다(`\n`을 넣으면 알려 줌). 그래서 수십 GB 파일도 줄 끝에서 끊어 읽으며 찾습니다. 바꿀 말에는 `$1`(그룹), `$&`·`$0`(찾은 전체), `$$`(`$` 글자), `\n`·`\t`(줄바꿈, 탭)를 쓸 수 있습니다. 문법이 틀리면 입력칸 아래에 이유가 나옵니다. UTF-8이 아닌 파일에서는 정규식에 ASCII 글자만 쓸 수 있습니다. 1MB가 넘는 한 줄은 조각으로 나눠 찾으므로 조각 경계를 걸치는 항목은 놓칠 수 있습니다.
- **대/소문자 보존** (`AB`): 찾은 글자가 모두 대문자면 바꿀 말도 대문자로, 모두 소문자면 소문자로, 첫 글자만 대문자면 첫 글자만 대문자로 바꿉니다. `-`나 `_`로 같은 수만큼 나뉘면 조각마다 따릅니다. 예를 들어 `steel`을 `alu`로 바꾸면 `STEEL`은 `ALU`, `Steel`은 `Alu`가 됩니다. 글자가 없는 항목(숫자)은 바꿀 말 그대로입니다.
- **선택 영역에서 찾기** (`≡`): 켤 때 선택한 범위 안에서만 찾고, 세고, 모두 바꿉니다. 범위는 배경색으로 보이고, 앞쪽을 편집해도 같은 글자를 따라갑니다. 선택이 없으면 켤 수 없고, 찾기 창을 닫으면 꺼집니다.

## 칸과 창

칸 수에 제한이 없고, 같은 파일을 여러 칸과 여러 창에 열 수 있습니다. 편집, 저장, 인코딩 변경은 그 파일을 보는 모든 칸과 창에 바로 반영되며, 실행 취소 기록도 함께 씁니다. 파일을 보는 마지막 칸이나 창을 닫을 때만 저장 여부를 묻습니다.

탭 줄 오른쪽에는 칸마다 분할 버튼(빈 칸을 만듦, Alt를 누르고 클릭하면 아래로), 잠겼을 때 나타나는 잠금 해제 버튼, `…` 메뉴가 있습니다.

- **열려 있는 편집기 표시**: 이 칸의 탭을 목록으로 보고 이름이나 경로로 찾아 고릅니다.
- **미리 보기 편집기 사용**: 탐색기에서 클릭한 파일은 이탤릭체 탭으로 열리고, 다음에 클릭한 파일이 그 자리를 대신합니다. 더블 클릭, 편집, 저장, 다른 칸으로 옮기기를 하면 일반 탭이 됩니다. 메뉴나 설정에서 끌 수 있습니다.
- **그룹 잠금**: 잠긴 칸에는 새 파일이 열리지 않고 다음 칸으로 가며, 모두 잠겼으면 새 칸이 생깁니다. 편집과 탭 옮기기는 그대로 됩니다.

본문을 오른쪽 클릭하면 모든 항목 변경, 잘라내기·복사·붙여넣기, 명령 팔레트, 열 색 구분이 있는 메뉴가 열립니다. 선택 영역 밖을 누르면 캐럿이 그리로 옮겨집니다.

**열 색 구분** (보기 메뉴, 설정에서도): CSV·TSV, Abaqus 데이터 줄, Nastran 카드의 필드마다 다른 색을 칠하고, 상태바에 캐럿이 있는 필드 번호를 보여 줍니다. Nastran은 카드 이름이 1번, 마지막 연속 필드가 10번(대형 필드는 6번)입니다.

탭을 오른쪽 클릭하면 그 탭에 대한 메뉴가 열립니다: 닫기, 다른 탭·오른쪽 탭·저장된 탭·모든 탭 닫기, 열린 상태 유지, 고정, 분할, 다른 칸으로 이동, 새 창으로 이동·복사. 고정한 탭은 탭 줄 맨 앞에 모이고, 여러 탭을 닫는 명령과 Ctrl+W, 가운데 클릭으로는 닫히지 않습니다. 탭의 메뉴에서 닫기를 고르면 닫힙니다.

새 창은 그 안에서 칸과 탭을 따로 가집니다. 다음 실행 때 복원되는 세션은 첫 번째 창의 것만이고, 설정은 모든 창이 함께 씁니다. 새 창에서 파일을 직접 열면 다른 창에 이미 열려 있어도 별개의 문서가 됩니다.

## Markdown 미리 보기

`.md` 파일이면 탭 줄 오른쪽에 VS Code처럼 버튼 두 개가 생깁니다 (보기 메뉴와 명령 팔레트에도 있음).

- **측면에서 미리 보기 열기** (Ctrl+K V): 오른쪽 칸에 "미리 보기 README.md" 탭을 엽니다 (오른쪽 칸이 없으면 새로 만듦). 키보드는 원본에 남아 계속 편집할 수 있고, 미리 보기는 입력이 멈추고 잠시 뒤 따라옵니다.
- **미리 보기 열기** (Ctrl+Shift+V): 이 칸에서 원본 대신 미리 보기를 보여 줍니다. 다시 누르거나 원본 보기 버튼을 누르면 원본으로 돌아옵니다.

GitHub식 문법(표, 체크 목록, 각주, 취소선, `> [!NOTE]` 알림)을 지원합니다. 웹·메일 링크는 기본 브라우저나 메일 프로그램으로 열립니다. 다른 파일 링크는 미리 보기가 있는 칸에 열리고(Markdown이면 미리 보기로), 폴더 링크는 탐색기에 보이며, `#제목` 링크는 그 제목으로 스크롤합니다. 이미지는 파일 기준 상대 경로로 불러옵니다.

문서 안의 HTML은 보여 줄 수 있는 것만 남습니다. 스크립트, 이벤트 처리기, `javascript:` 링크, 스타일, iframe, form은 지웁니다 (미리 보기가 앱 화면의 일부라서). 16 MB가 넘는 파일은 미리 보지 않습니다.

미리 보기를 오른쪽 클릭하면 복사, 모두 선택, 원본 보기 메뉴가 열립니다. 미리 보기 상태는 세션과 함께 복원됩니다.

## 탐색기 메뉴

탐색기에서 오른쪽 클릭하면 VSCode와 비슷한 메뉴가 열립니다. 파일, 폴더, 빈 공간(선택한 항목의 폴더를 대상으로 함)마다 항목이 다릅니다. 탐색기에 포커스가 있을 때 단축키도 같습니다. 탐색기 위쪽의 새 파일, 새 폴더 버튼은 빈 공간의 메뉴처럼 선택한 폴더(파일이면 그 파일이 있는 폴더)에 만듭니다.

| 항목 | 단축키 | 동작 |
|---|---|---|
| 새 파일…, 새 폴더… | | 폴더 맨 위에 이름 칸이 생김. 이미 있는 이름이나 `/`, `\`가 들어간 이름은 입력하는 동안 알려 줌. Enter로 만들고 Esc로 취소. 다른 곳을 누르면 만듦. 새 파일은 바로 탭으로 열림 |
| 측면에서 열기 | Ctrl+Enter | 오른쪽 칸에 열기 (없거나 잠겼으면 새 칸) |
| 파일 탐색기에 표시 (Mac은 Finder) | Shift+Alt+R | OS 파일 관리자에서 그 항목을 선택해 보여 줌 |
| 터미널에서 열기 | | 그 폴더(파일이면 파일이 있는 폴더)에서 OS 터미널을 엶. Windows는 Windows Terminal, 없으면 명령 프롬프트 |
| 잘라내기, 복사, 붙여넣기 | Ctrl+X, Ctrl+C, Ctrl+V | 폴더째로도 됨. 복사한 것은 같은 이름이 있으면 `deck copy.inp`, `deck copy 2.inp`가 됨. 옮길 때 같은 이름이 있으면 덮어쓰지 않고 멈춤. 폴더를 자기 안으로 넣을 수 없음. 파일 위에서 붙여넣으면 그 파일의 폴더로 |
| 경로 복사 | Shift+Alt+C | 전체 경로 |
| 상대 경로 복사 | | 편집 중인 파일의 폴더 기준 경로 (`*INCLUDE, INPUT=`에 바로 붙여넣기 좋게). 드라이브가 다르면 쓸 수 없음 |
| 이름 바꾸기… | F2 | 확장자를 뺀 이름이 선택됨. 대소문자만 바꿔도 됨 |
| 삭제 | Delete | 확인을 거쳐 휴지통으로 |

이름을 바꾸거나 옮긴 파일(폴더 안의 파일 포함)이 열려 있으면 탭이 새 경로를 따라가고, 저장도 새 경로에 합니다. 다른 창의 탭도 같이 따라갑니다. 열려 있는 파일을 삭제하면 "디스크에서 파일이 변경되었습니다." 알림이 뜨고, 탭의 내용은 그대로 남아 저장하면 다시 만들어집니다. 드라이브와 빠른 접근 폴더는 자르기·복사·이름 바꾸기·삭제를 할 수 없습니다.

## 문법 강조

Abaqus, Nastran 외에 Python, Shell, Batch, PowerShell, Java, C/C++, JavaScript/TypeScript, Rust, Go, Fortran(고정·자유 형식), TOML, YAML, JSON, INI, XML/HTML, Markdown을 확장자로 구분합니다. 여러 줄 주석과 문자열은 파일 앞 16 MB까지 위에서부터 읽어 판단하고, 그보다 뒤에서는 화면 첫 줄부터 새로 판단합니다 (큰 파일이 느려지지 않도록).

## 설정

Ctrl+, 또는 파일 메뉴의 설정으로 엽니다. Windows 대화 상자처럼 바꾼 값은 **적용**이나 **확인**을 눌러야 반영되고, **취소**·Esc·Ctrl+,로 닫으면 버려집니다. 입력란에서 Enter는 확인입니다. **기본값으로 되돌리기**도 창 안의 값만 바꾸므로 적용해야 반영됩니다. 이 창에서 바꾼 항목만 반영되어, 그사이 다른 창이나 보기 메뉴에서 바꾼 다른 설정은 그대로 남습니다. 설정은 다른 PC로 복사할 수 있는 파일에 저장됩니다 (Windows: `%APPDATA%\dev.hueditor.editor\settings.json`).

- **일반**: 언어 (English / 한국어, 처음에는 OS 언어를 따름), 시작할 때 지난 파일 다시 열기, 자동 저장, 탐색기에 숨김 파일 표시
- **편집기**: 글꼴(직접 입력하거나 ▾·↓로 여는 목록에서 고름. 목록에는 이 PC에 설치된 고정폭 글꼴이 그 글꼴 모양으로 나옴)과 크기, 줄 번호, 현재 줄 강조, 미리 보기로 열기, Tab 키 입력 (스페이스 칸 수 또는 탭 문자), 문법 강조, Nastran 필드 음영, 열 색 구분
- **파일**: 새 파일의 인코딩·줄바꿈, UTF-8이 아닌 파일의 인코딩 (이후 여는 파일에 적용), 내용으로 판단할 수 없는 `.blk` 파일의 솔버
- **단축키**: 메뉴별로 묶은 목록 (변경은 아직 안 됨)

언어를 추가하려면 `app/src/lib/i18n/`에 파일을 하나 더 만듭니다. 인코딩·솔버·카드 이름과 OS가 주는 오류 메시지는 번역하지 않습니다.
