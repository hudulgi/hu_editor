# HU Editor

Abaqus·Nastran 해석 입력 파일(`.inp`, `.bdf`, `.dat`, `.nas`)을 위한 Windows용 텍스트 편집기입니다. 수백 MB에서 수십 GB에 이르는 덱도 파일 전체를 읽어 들이지 않고 바로 열어 편집합니다. 화면과 단축키는 VS Code와 비슷하게 만들었습니다.

## 주요 기능

- **큰 파일**: 필요한 부분만 디스크에서 읽어서 큰 파일도 바로 열립니다. 줄 수는 백그라운드에서 세며, 그동안에도 스크롤, 편집, 찾기를 할 수 있습니다.
- **해석 입력 파일**: Abaqus 키워드와 Nastran 카드 강조, Nastran 필드 음영, 필드마다 다른 색과 상태바의 필드 번호, `**`·`$` 주석, 키워드 블록·카드 단위 선택, `*INCLUDE`에 붙일 상대 경로 복사를 지원합니다.
- **찾기와 바꾸기**: 정규식, 단어 단위(소수점을 숫자의 일부로 봄), 대/소문자 보존, 선택 영역에서 찾기, 일치 개수, 여러 파일에서 찾기와 바꾸기를 지원합니다.
- **편집**: 박스(열) 선택, 줄 이동·복사, 인코딩을 바꿔 다시 읽기와 저장(CP949 등)을 지원합니다.
- **화면**: 탭, 원하는 만큼 칸 나누기, 여러 창, PC 전체를 보는 탐색기, Markdown 미리 보기, 명령 팔레트가 있습니다.
- **파일 비교**: 수정 전후의 덱을 줄 단위로 나란히 비교하고, 바뀐 값을 줄 안에서 짚어 주고, 차이를 한쪽에서 다른 쪽으로 복사합니다. 수 GB 파일도 비교합니다.
- 화면 언어는 한국어와 영어입니다.

## 설치

[Releases](https://github.com/hudulgi/hu_editor/releases/latest)에서 받습니다. Windows 10/11 64비트용입니다.

| 파일 | 용도 |
|---|---|
| `…_x64-setup.exe` | 설치 파일입니다. 관리자 권한 없이 사용자 계정에 설치됩니다. |
| `…_x64-portable.zip` | 설치 없이 쓰는 휴대용입니다. 아무 폴더에 풀어 `HU Editor.exe`를 실행합니다. 함께 든 `THIRD_PARTY_NOTICES.txt`는 같은 폴더에 둡니다. |
| `….msi` | IT 부서가 여러 PC에 한꺼번에 배포할 때 씁니다. |

- **경고 창:** 서명하지 않은 프로그램이라, 설치 파일이나 휴대용 `HU Editor.exe`를 처음 실행할 때 경고 창이 두 번 뜰 수 있습니다. 관리자 권한은 묻지 않습니다.
  - "Windows의 PC 보호" 창에서는 **추가 정보 → 실행**을 누릅니다.
  - "게시자를 확인할 수 없습니다" 창에서는 **실행**을 누릅니다.
- **휴대용 zip:** WebView2 런타임이 있어야 합니다. Windows 11과 업데이트된 Windows 10에는 기본으로 있습니다.
- **업데이트:** 자동으로 되지 않습니다. 새 버전을 받아 다시 설치하거나 zip을 바꿉니다. 설정과 열던 파일은 그대로 남습니다.

## 시작하기

- **열기:** 여러 가지 방법이 있습니다.
  - Ctrl+O로 엽니다. 텍스트 파일이면 확장자와 상관없이 열립니다. 열기 창은 모든 파일을 보여 주고, 파일 형식에서 해석 입력 파일, 해석 결과 파일(`.f06`·`.msg`·`.sta` 등), 텍스트 파일, 언어별로 좁힐 수 있습니다.
  - Windows 탐색기에서 끌어다 놓습니다.
  - 왼쪽 탐색기(Ctrl+B)에서 클릭합니다.
  - 끌어다 놓을 때 칸 가운데에 놓으면 그 칸에, 글자 영역 가장자리에 놓으면 그쪽에 새 칸을 만들어 엽니다. 폴더를 놓으면 탐색기에서 펼칩니다.
- **저장:** Ctrl+S로 저장합니다. 임시 파일에 다 쓴 뒤 원본과 바꾸므로, 저장 중에 끊겨도 원본은 망가지지 않습니다. 다른 이름으로 저장 창에는 지금 파일의 형식이 먼저 골라져 있어서, 확장자 없이 이름만 적으면 그 확장자가 붙습니다.
- **다시 열기:** 다음에 실행하면 열던 파일과 칸 배치가 돌아옵니다. 설정에서 끌 수 있습니다.
- **메뉴:** Alt나 F10으로 메뉴 막대로 갑니다. 모든 명령은 명령 팔레트(Ctrl+Shift+P)에서 이름으로 찾아 실행할 수 있습니다.

## 해석 입력 파일 다루기

- **문법 강조:**
  - `.inp`는 Abaqus로, `.bdf`·`.dat`·`.nas`는 Nastran으로 강조합니다.
  - `.blk`는 내용을 보고 솔버를 정합니다. 내용으로 알 수 없으면 설정의 기본값을 씁니다.
  - 그 밖에 Python, Shell, Batch, PowerShell, Java, C/C++, JavaScript/TypeScript, Rust, Go, Fortran(고정·자유 형식), TOML, YAML, JSON, INI, XML/HTML, Markdown을 확장자로 구분합니다.
- **Nastran 필드 음영:** 카드의 필드를 하나 걸러 옅은 배경으로 칠해 필드 경계가 보이게 합니다.
- **열 색 구분** (보기 메뉴): CSV·TSV, Abaqus 데이터 줄, Nastran 카드의 필드마다 다른 색을 칠합니다. 상태바에는 커서가 있는 필드의 번호가 나옵니다. Nastran은 카드 이름이 1번, 마지막 연속 필드가 10번(대형 필드는 6번)입니다.
- **Tab:** 다음 8칸 경계까지 공백으로 채웁니다(Nastran 소형 필드). 칸 수와 탭 문자 사용은 설정에서 바꿉니다.
- **주석:** Ctrl+/로 줄 주석을 넣거나 뺍니다. Abaqus는 `**`, Nastran은 `$`를 줄 맨 앞에 넣습니다.
- **선택 확장:** Ctrl+Shift+Alt+→를 누를 때마다 선택이 넓어집니다. 단어 → 필드(쉼표, Nastran 8·16칸) → 줄의 글자 → 줄 → 블록(Abaqus 키워드와 그 데이터 줄, Nastran 카드와 이어지는 줄) → 전체 순서입니다. ←는 거꾸로 좁힙니다.
- **박스 선택:** Alt+드래그로 고릅니다. 입력, 삭제, 붙여넣기가 모든 줄에 한꺼번에 적용되어, 같은 열의 값을 한 번에 고치기 좋습니다.
- **단어 단위 찾기:** 소수점을 숫자의 일부로 봅니다. 그래서 `101`을 찾으면 `0.101`, `101.5`, `1010`은 건너뛰고 `-101`은 찾습니다. 점 너머가 이름이면 따로 봐서, `Part-1-1.Set-1`에서는 `Part-1-1`과 `Set-1`을 각각 찾습니다.
- **상대 경로 복사:** 탐색기에서 파일을 오른쪽 클릭해 고릅니다. 편집 중인 파일의 폴더를 기준으로 한 경로가 복사되어, `*INCLUDE, INPUT=`에 바로 붙여 넣을 수 있습니다.
- **인코딩:** 상태바의 인코딩 표시를 눌러 다른 인코딩으로 다시 읽거나(파일은 그대로), 변환해서 저장합니다. UTF-8이 아닌 파일을 처음 열 때 쓸 인코딩(기본 CP949)은 설정에서 정합니다.

## 큰 파일

- **열기:** 파일 전체를 메모리에 올리지 않습니다. 줄 번호 색인을 만드는 동안에도 바로 스크롤하고 편집할 수 있습니다.
- **찾기:** 수십 GB 파일도 줄 단위로 끊어 읽으며 찾습니다. 큰 파일에서 일치 개수를 셀 때는 진행률이 보입니다.
- **모두 바꾸기:** 한 번에 실행 취소할 수 있고, 최대 200만 건까지 바꿉니다.
- **저장:** 파일 전체를 다시 쓰므로 수 GB 파일은 시간이 걸립니다. 그런 파일에서는 자동 저장을 꺼 두는 편이 좋습니다.
- **문법 강조:** 여러 줄에 걸친 주석과 문자열은 파일 앞 16 MB까지만 처음부터 읽어 판단합니다. 그보다 뒤에서는 화면 첫 줄부터 새로 판단합니다.

## 찾기와 바꾸기

찾기 창(Ctrl+F, 바꾸기는 Ctrl+H)은 VS Code처럼 편집 영역 오른쪽 위에 떠 있습니다. 선택한 글자가 있으면 그 글자가 찾을 말로 들어가고, 화면에 보이는 일치 항목은 모두 강조됩니다.

- **개수:** 찾을 말 옆에 `3/120`처럼 지금 항목의 순서와 전체 개수가 나옵니다.
- **대/소문자 구분** (Alt+C), **단어 단위** (Alt+W, `ab`): 기본은 둘 다 꺼져 있습니다. Abaqus와 Nastran이 대소문자를 가리지 않기 때문입니다.
- **정규식** (Alt+R, `.*`):
  - 한 줄 안에서 찾습니다. `^`와 `$`는 줄의 처음과 끝입니다.
  - 바꿀 말에는 `$1`(그룹), `$&`(찾은 전체), `\n`·`\t`(줄바꿈, 탭)를 쓸 수 있습니다.
  - 문법이 틀리면 입력칸 아래에 이유가 나옵니다.
  - UTF-8이 아닌 파일에서는 정규식에 ASCII 글자만 쓸 수 있습니다.
- **대/소문자 보존** (Alt+P, `AB`): 찾은 글자의 대소문자를 따라 바꿉니다. 예를 들어 `steel`을 `alu`로 바꾸면 `STEEL`은 `ALU`, `Steel`은 `Alu`가 됩니다.
- **선택 영역에서 찾기** (Alt+L, `≡`): 켤 때 선택한 범위 안에서만 찾고, 세고, 바꿉니다.
- **모든 항목 변경** (Ctrl+F2): 커서가 있는 단어를 찾을 말로 넣고 바꿀 말 입력으로 바로 갑니다.

**파일에서 찾기** (Ctrl+Shift+F, 바꾸기는 Ctrl+Shift+H): 사이드바의 검색 보기에서 한 폴더 안의 파일을 모두 찾습니다.
- **검색할 폴더:** 처음에는 열려 있는 파일의 폴더가 들어갑니다.
- **파일 거르기:** `…` 버튼을 누르면 포함할 파일과 제외할 파일을 `*.inp, sub/*.bdf`처럼 적을 수 있습니다.
- **찾는 대상:** 열려 있는 파일은 저장하지 않은 내용까지 찾습니다. 숨김 파일과 이진 파일은 건너뜁니다.
- **모두 바꾸기:** 몇 개 파일의 몇 개 항목을 바꿀지 먼저 묻습니다.
  - 열려 있지 않은 파일은 바꾸고 바로 저장합니다.
  - 열려 있는 파일은 편집기에서 바꾼 채로 둬서 실행 취소할 수 있습니다. 저장은 직접 합니다.

## 칸과 창

- **칸 나누기:** 칸 수에 제한이 없습니다.
  - Ctrl+\나 탭 줄의 분할 버튼은 빈 칸을 만듭니다. 다음에 여는 파일이 그 칸에 열립니다.
  - 보기 > 편집기 레이아웃에서 두 개 열, 그리드 같은 배치를 고를 수 있습니다.
  - 칸이 여럿일 때 빈 칸 오른쪽 위의 X로 그 칸을 닫습니다.
- **같은 파일을 나란히:** 탭을 오른쪽 클릭해 오른쪽으로 분할합니다. 편집, 저장, 실행 취소는 그 파일을 보는 모든 칸과 창에 함께 반영됩니다.
- **탭 옮기기:** 탭을 다른 칸으로 끌어 옮깁니다. 칸 가장자리에 놓으면 그쪽에 새 칸이 생깁니다. 키보드로는 Ctrl+Alt+→/←입니다.
- **미리 보기 탭:** 탐색기에서 한 번 클릭한 파일은 이탤릭체 탭으로 열리고, 다음에 클릭한 파일이 그 자리를 대신합니다. 더블 클릭하거나 편집하면 일반 탭이 됩니다. 설정에서 끌 수 있습니다.
- **고정 탭:** 탭 메뉴에서 고정하면 탭 줄 맨 앞에 남습니다. 여러 탭을 한꺼번에 닫는 명령으로는 닫히지 않습니다.
- **그룹 잠금** (`…` 메뉴): 잠긴 칸에는 새 파일이 열리지 않습니다.
- **새 창** (Ctrl+Shift+N): 그 안에서 칸과 탭을 따로 가집니다. 다음 실행 때 돌아오는 것은 첫 번째 창의 파일과 배치입니다.
- **오른쪽 클릭 메뉴:** 본문을 오른쪽 클릭하면 잘라내기·복사·붙여넣기와 명령 팔레트가, 탭을 오른쪽 클릭하면 닫기·고정·분할·이동 메뉴가 열립니다.

## 탐색기

왼쪽 탐색기(Ctrl+B)는 PC의 드라이브와 폴더를 모두 보여 줍니다. 위쪽 주소창에 경로를 붙여 넣어 바로 갈 수 있습니다. 항목을 오른쪽 클릭하면 다음 메뉴가 열립니다.

| 항목 | 단축키 | 동작 |
|---|---|---|
| 새 파일…, 새 폴더… | | 선택한 폴더에 만듭니다. 이미 있는 이름이면 입력하는 동안 알려 줍니다. |
| 측면에서 열기 | Ctrl+Enter | 오른쪽 칸에 엽니다. |
| 파일 탐색기에 표시 | Shift+Alt+R | Windows 탐색기에서 그 항목을 보여 줍니다. |
| 터미널에서 열기 | | 그 폴더에서 Windows Terminal(없으면 명령 프롬프트)을 엽니다. |
| 잘라내기, 복사, 붙여넣기 | Ctrl+X, Ctrl+C, Ctrl+V | 같은 이름이 있으면 `deck copy.inp`처럼 이름을 바꿔 복사하고, 옮길 때는 덮어쓰지 않고 멈춥니다. |
| 경로 복사 | Shift+Alt+C | 전체 경로를 복사합니다. |
| 비교할 파일로 선택, '…' 파일과 비교 | | 한 파일을 고른 뒤 다른 파일에서 고르면, 두 파일을 [비교 창](#파일-비교)에 엽니다. |
| 선택한 두 파일 비교 | | 두 파일을 골랐을 때 나옵니다. 먼저 고른 파일이 왼쪽에 옵니다. |
| 상대 경로 복사 | | 편집 중인 파일의 폴더 기준 경로를 복사합니다. |
| 이름 복사 | | 확장자를 포함한 이름만 복사합니다(`deck.inp`). |
| 이름 바꾸기… | F2 | 확장자를 뺀 이름이 선택됩니다. |
| 삭제 | Delete | 확인을 거쳐 휴지통으로 보냅니다. |

이름을 바꾸거나 옮긴 파일이 열려 있으면 탭이 새 경로를 따라갑니다.

**즐겨찾기**
- **추가:** 자주 쓰는 파일이나 폴더를 오른쪽 클릭해 **즐겨찾기에 추가**를 고르면, 탐색기 맨 위의 즐겨찾기에 들어갑니다. 여러 개를 골랐으면 한꺼번에 들어갑니다.
- **표시:** 이름 옆에는 그 항목이 있는 폴더가 흐리게 보입니다.
- **쓰기:** 즐겨찾기의 파일을 누르면 열리고, 폴더는 그 자리에서 펼쳐집니다.
- **바로 가기일 뿐:** 즐겨찾기 항목 자체는 잘라내기·이름 바꾸기·삭제가 되지 않습니다. 빼려면 오른쪽 클릭해 **즐겨찾기에서 제거**를 고릅니다. 원본 파일은 그대로 남습니다.
- **따라가기:** 탐색기에서 이름을 바꾸거나 옮기면 즐겨찾기도 따라갑니다. 디스크에서 사라진 항목은 흐리게 보입니다.
- **저장:** 즐겨찾기는 모든 창이 함께 쓰고, 다음 실행 때도 남습니다.

**여러 개 고르기**
- **고르는 법:**
  - Ctrl+클릭(Mac은 Cmd+클릭)으로 하나씩 더하거나 뺍니다.
  - Shift+클릭으로 마지막에 고른 것부터 그 항목까지 고릅니다.
  - 키보드로는 Shift+↑/↓로 넓히고, Esc로 하나만 남깁니다.
  - 이렇게 고를 때는 파일이 열리지 않습니다.
- **함께 되는 것:** 고른 항목에 대해 잘라내기, 복사, 삭제, 경로·이름 복사가 한꺼번에 됩니다.
  - 삭제는 한 번만 묻습니다.
  - 경로와 이름은 한 줄에 하나씩 복사됩니다.
  - 폴더와 그 안의 파일을 함께 고르면 폴더만 지우거나 옮깁니다.
- **열기:** Enter를 누르면 고른 파일이 모두 열립니다. 편집기로 끌어다 놓아도 모두 열립니다.
- **오른쪽 클릭:** 고른 항목 위에서 누르면 선택이 그대로 남고, 다른 항목에서 누르면 그 항목 하나만 고릅니다.
- **하나일 때만:** 이름 바꾸기와 측면에서 열기는 하나만 골랐을 때만 됩니다.

## 파일 비교

두 파일을 줄 단위로 나란히 보여 주는 창입니다. 수정 전후의 덱이나 비슷한 덱의 차이를 찾는 데 씁니다. 수 GB 파일도 비교합니다.

- **여는 법:**
  - 왼쪽 아이콘 줄의 **비교**(세 번째 아이콘)를 누르면 사이드바에 비교 보기가 열립니다. 왼쪽과 오른쪽 칸에 파일을 하나씩 넣고 **비교**를 누릅니다.
    - 칸마다 경로를 입력하거나 붙여 넣고, 폴더 버튼으로 파일을 고르거나, 문서 버튼으로 편집 중인 파일을 넣습니다.
    - Windows 탐색기에서 칸으로 끌어다 놓아도 됩니다. 두 파일을 함께 놓으면 양쪽에 하나씩 들어갑니다.
    - 위쪽 버튼으로 왼쪽과 오른쪽을 맞바꾸거나 비웁니다. 넣은 파일은 다음 실행 때도 남습니다.
  - 탐색기에서 두 파일을 Ctrl+클릭으로 고르고, 오른쪽 클릭해 **선택한 두 파일 비교**를 고릅니다. 먼저 고른 파일이 왼쪽에 옵니다.
  - 탐색기에서 한 파일에 **비교할 파일로 선택**을 고른 뒤, 다른 파일에서 **'…' 파일과 비교**를 고릅니다. 고른 파일은 비교 보기의 왼쪽 칸에도 들어갑니다.
  - 파일 > **현재 파일과 비교…**: 고른 파일이 왼쪽, 편집 중인 파일이 오른쪽에 옵니다.
- **보는 법:** 차이가 나는 줄은 종류마다 색과 기호가 다릅니다. 기호는 줄 번호 옆에 나옵니다.

  | 색 | 기호 | 뜻 |
  |---|---|---|
  | 파랑 (양쪽) | `~` | 양쪽에 다 있지만 내용이 바뀐 줄. 바뀐 값만 더 진하게 칠합니다. |
  | 빨강 (왼쪽) | `−` | 왼쪽에만 있는 줄 |
  | 초록 (오른쪽) | `+` | 오른쪽에만 있는 줄 |

  - 한쪽에만 있는 줄의 맞은편에는 위아래에 선을 그은 빗금 칸이 들어갑니다.
  - 숫자는 지수(`1.5E+03`)까지 한 덩어리로 보고 바뀐 값을 칠합니다.
  - 오른쪽 끝 막대에 차이가 있는 곳이 같은 색으로 표시됩니다. 누르거나 끌면 그곳으로 갑니다.
  - 상태 막대에 "차이 3개 · 바뀐 줄 2, 왼쪽에만 1"처럼 무엇이 다른지 나옵니다. 차이를 고르면 그 차이의 내용이 나옵니다.
- **차이 사이 이동:** F7 / Shift+F7(또는 Alt+↓ / ↑)로 다음 / 이전 차이로 갑니다. 두 칸 사이 막대 위의 ˄ ˅ 버튼도 같습니다. Alt+Home / End는 처음 / 마지막 차이입니다. 줄을 클릭해도 그 차이를 고릅니다.
- **복사:** Alt+→는 고른 차이를 오른쪽으로, Alt+←는 왼쪽으로 복사합니다. 두 칸 사이의 ›, ‹ 버튼으로도 됩니다.
  - 복사한 줄은 받는 파일의 인코딩과 줄바꿈(CRLF/LF)에 맞춰 들어갑니다.
  - Ctrl+Z, Ctrl+Y로 되돌리고 다시 합니다.
- **저장:** Ctrl+S는 바뀐 쪽을 모두 저장합니다. 파일 메뉴에서 한쪽만 저장할 수도 있습니다. 저장하지 않은 채 창을 닫으면 묻습니다.
- **편집기와 함께:** 편집기에 열려 있던 파일은 저장하지 않은 내용까지 비교합니다. 비교 창에서 복사한 내용은 편집기에도 바로 보이고, 편집기에서 고친 내용은 비교 창에 바로 반영됩니다.
- **같은 줄의 기준:** 줄 내용이 글자 하나까지 같아야 같은 줄입니다. 줄바꿈 방식의 차이만은 무시합니다.
- **메모리:** 줄마다 짧은 요약값(해시)만 기억합니다. 1 GB 파일 둘을 비교할 때 1 GB 안팎을 씁니다.

## Markdown 미리 보기

`.md` 파일을 열면 탭 줄 오른쪽에 VS Code처럼 버튼 두 개가 생깁니다.

- **측면에서 미리 보기 열기** (Ctrl+K V): 오른쪽 칸에 미리 보기를 엽니다. 원본을 계속 편집하면 미리 보기가 잠시 뒤 따라옵니다.
- **미리 보기 열기** (Ctrl+Shift+V): 이 칸에서 원본 대신 미리 보기를 보여 줍니다. 다시 누르면 원본으로 돌아옵니다.

GitHub식 문법(표, 체크 목록, 각주, `> [!NOTE]` 알림)을 지원합니다.
- **링크:** 웹 링크는 브라우저로, 다른 파일 링크는 편집기로, `#제목` 링크는 그 제목으로 갑니다.
- **보안:** 문서 안의 스크립트는 실행하지 않습니다.
- **크기:** 16 MB가 넘는 파일은 미리 보지 않습니다.

## 설정

Ctrl+, 또는 파일 메뉴의 설정으로 엽니다. 바꾼 값은 **적용**이나 **확인**을 눌러야 반영되고, **취소**나 Esc로 닫으면 버려집니다.

- **일반**: 언어, 시작할 때 지난 파일 다시 열기, 자동 저장, 탐색기에 숨김 파일 표시
- **편집기**: 글꼴과 크기, 줄 번호, 현재 줄 강조, 미리 보기로 열기, Tab 키 입력, 문법 강조, Nastran 필드 음영, 열 색 구분
- **파일**: 새 파일의 인코딩과 줄바꿈, UTF-8이 아닌 파일의 인코딩, 내용으로 알 수 없는 `.blk` 파일의 솔버
- **단축키**: 메뉴별 단축키 목록 (아직 바꿀 수는 없음)

설정은 `%APPDATA%\dev.hueditor.editor\settings.json`에 저장됩니다. 다른 PC로 복사해 쓸 수 있습니다.
